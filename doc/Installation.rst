.. _INSTALL/pip:

Using PIP to Install from PyPI
******************************

The following instructions use PIP (Package Installer for Python) as a package manager and PyPI (Python Package Index)
as a source of Python packages.

.. tab-set::

   .. tab-item:: Linux/macOS
      :sync: Linux

      .. code-block:: bash

         # Install pyTooling.GitHub
         pip3 install pyTooling.GitHub

         # Update pyTooling.GitHub
         pip3 install -U pyTooling.GitHub

         # Uninstall pyTooling.GitHub
         pip3 uninstall pyTooling.GitHub

   .. tab-item:: Windows
      :sync: Windows

      .. code-block:: powershell

         # Install pyTooling.GitHub
         pip install pyTooling.GitHub

         # Update pyTooling.GitHub
         pip install -U pyTooling.GitHub

         # Uninstall pyTooling.GitHub
         pip uninstall pyTooling.GitHub
